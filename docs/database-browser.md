# 数据浏览器

设计日期：2026-10-18。入口为本机 Web 应用的 `/database`，聊天页提供“数据浏览器”链接。

## 功能与范围

- 公共校园库：课程、教室、排课、教学周和学期事件。
- 我的数据：当前登录账号的成绩、选课与会话登记；服务端按账号过滤。
- 政策文档：当前公开 Markdown 快照，明确区分文件与已建索引。
- 向量索引：按需读取配置的 Milvus 或 Chroma，查看实际分块与元数据。
- 数据表支持搜索、分页和记录详情；结构视图展示字段；关系视图注明物理或逻辑关联。

浏览器沿用现有登录；未登录时引导回首页。只提供读取入口，表名和字段由服务端白名单决定。
密码、令牌、其他账号数据、会话正文、画像和本机原始学生评价不在展示范围内。
连接错误只显示可恢复的状态；页面不展示连接字符串。索引读取不调用模型或 Embedding，不创建或重建集合。

## 视觉方案

沿用校园主题：深蓝 `#103042`、青绿 `#087b79`、浅灰绿 `#f2f6f5`、白色 `#ffffff`、
次要文字 `#5e727c` 与边线 `#d5e2e0`。中文使用系统黑体，字段标识使用等宽字体。

桌面采用“左侧数据来源与表目录、右侧记录工作区”，右侧详情按需打开。
以可横向滚动的数据表为中心，状态和记录范围直接放在表头，避免用大量统计卡片分散注意力。
移动端目录折叠成选择区，详情使用原生对话框；键盘焦点、加载、空数据和失败状态均有明确反馈。

```text
数据浏览器                                      返回对话
数据来源与表目录  | 表名、来源说明              刷新
公共校园库        | 数据记录 / 字段结构 / 表间关系
  课程            | 搜索…                    每页数量
  教室            | 字段     字段     字段
我的数据          | 记录     记录     查看
政策文档          | 记录范围                 上页 下页
向量索引          | 按需连接，失败可重试
```

沿用现有产品的字体与色彩，把辨识度放在清晰的表目录和关联说明上。

## 验证

离线 API 测试使用临时校园库、临时账号库及索引客户端替身，覆盖鉴权、用户隔离、
白名单、搜索转义、分页、排序、故障反馈与只读约束。浏览器检查运行在专用临时测试应用。
实现与验证结果：

- 15 项 API 测试通过，包含真实临时 Chroma 集合的读取，无 Embedding 请求。
- 数据浏览器 9 组浏览器检查通过，覆盖搜索、分页、关联跳转、详情、移动端与账号切换。
- 原有聊天页面的 10 组浏览器回归通过，无页面脚本异常。
- 全项目 11 组隔离离线检查通过；Python 编译、JavaScript 语法与差异格式检查通过。
- Milvus 适配通过客户端替身验证；本机默认 `localhost:19530` 当前无法连接，未验证真实集合读取。
- PostgreSQL 的只读事务与用户过滤通过参数契约验证，未连接真实账号库。

## 使用

按原有方式启动或重启应用，登录后点击右上角“数据浏览器”，也可访问
`http://127.0.0.1:8000/database`。不需要安装额外的前端依赖。

1. 左侧选择数据来源和表，默认显示课程目录。
2. 输入关键词搜索；公共库、个人数据和快照可点击列标题排序。
3. 点击“查看”展开完整记录；`Escape` 或“关闭”返回。
4. “字段结构”展示可见字段与记录标识；“表间关系”可跳转到关联表。
5. 选择“已入库分块”才连接向量库。服务未就绪时显示重试入口，仍可查看政策文件。

网页接口：`GET /api/database` 返回允许浏览的目录；
`GET /api/database/{source}/{table}` 返回分页、字段和记录。
参数包括 `q`、`page`、`page_size`、`sort` 和 `direction`。
每页最多 100 条，最多浏览前 10000 条；个人数据的所有计数与搜索均在账号过滤后执行。

向量索引暂不支持字段排序，搜索按正文包含词匹配；Chroma 搜索结果不统计全量匹配条数。
全文在详情中最多展示 20000 个字符，截断会明确提示。字段结构是浏览器的白名单投影，
不是完整内部表结构。政策快照与实际索引可能版本不同，浏览页面不会自动同步。
