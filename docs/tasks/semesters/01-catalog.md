## 1. 位置

阶段 3 多学期数据可以独立使用。本任务落实 R-1 学期归属明确。
起点是旧公共结构；个人数据与工具改造依赖学期登记。
范围为公开校历与排课，不重建现用数据库。

## 2. 开发上下文

**先读**
- scripts/init_db.py — 旧周次和排课如何存储？
- data/structured/seed_academic_cal.json — 唯一已录入学期的真实范围是什么？
- src/student_data.py — 旧个人记录用什么学期名称？

**已定**：学期 ID 与显示名称分开；旧个人存储名称兼容；详见 plan.md。
**边界与入口**：学期登记、迁移和导入公开函数；迁移是独立命令，读取旧库不写入。
**运行**：`.venv\python.exe scripts/test_semesters.py`；`.venv\python.exe -m compileall -q src scripts`。
**未知**：旧校历若混杂多个学期而排课无归属，停止迁移并报告，保留原库。

## 3. 步骤

1. 阅读上下文，重述任务：给公开资料明确且可迁移的学期归属。
2. 写旧库、双学期与失败回滚用例并提交。
3. 实现学期读取、迁移与事务导入。
4. 接入显式初始化和导入命令，验证不覆盖其他学期。
5. 运行检查并提交实现。

## 4. 用例

| 场景 | 输入 | 期望 | 入口 |
|---|---|---|---|
| 旧库 | 唯一旧学期 | 只读可查，迁移保留记录 | 学期登记 |
| 新学期 | 第 1 周重复编号 | 独立保存 | 导入 |
| 失败 | 不存在的课程或版本不符 | 整个导入回滚 | 导入 |
| 重复 | 内容不变 | 版本不增加 | 导入 |
| 缺资料 | 排课未提供 | 状态未录入 | 学期登记 |
