## 2. 意义

学期 ID 与名称、建议开课月份分开，教学周和排课不再依赖固定九月学期。
没有排课时会说明无法确认；导入时段与查询时段部分重叠也会计为占用。
新成绩保存课程名称和学分，旧成绩缺快照时明确提示回退，报告只计算所选学期 GPA。
