## 4. 用例

| 场景 | 输入 | 期望 | 入口 |
|---|---|---|---|
| 切换 | 学期 A 与 B | 列表和写入各自独立 | 浏览器 |
| 恢复 | 刷新待确认操作 | 恢复原学期 | HTTP / 浏览器 |
| 冲突 | 用 B 学期确认 A 操作 | 409，不执行 | HTTP |
| 并发 | 切换后旧请求返回 | 不回填旧记录 | 浏览器 |
| 兼容 | 不传学期的旧请求 | 确定默认学期并标明 | HTTP |
