## 1. 位置

阶段 3 多学期数据可以独立使用。本任务落实 R-2 个人数据与工具按学期查询。
学期登记完成后开始；网页选择依赖这些带范围的函数。
范围为查询与个人录入，不计算累计 GPA。

## 2. 开发上下文

**先读**
- src/student_data.py — 账号和学期过滤在哪里？
- src/tools/academic.py — 日期与事件有哪些固定假设？
- src/tools/timetable.py — 缺排课是否被当成空闲？
- src/tools/gpa.py — 学分和成绩怎样组成报告？

**已定**：显式学期优先，其次上下文；成绩保存当时学分；详见 plan.md。
**边界与入口**：个人数据函数、工具与 HTTP；身份仍由服务端注入。
**运行**：`.venv\python.exe scripts/test_semester_data.py`；`.venv\python.exe -m compileall -q src scripts`。
**未知**：旧成绩无法恢复历史学分，回退当前目录并说明；不得伪造历史快照。

## 3. 步骤

1. 阅读上下文，重述任务：每次业务查询明确使用哪个学期。
2. 写跨学期隔离、校历缺口与 GPA 快照失败用例并提交。
3. 实现个人记录范围和学分兼容。
4. 改造工具参数、运行上下文和缺数据返回。
5. 运行检查并提交实现。

## 4. 用例

| 场景 | 输入 | 期望 | 入口 |
|---|---|---|---|
| 成绩 | 同账号同课程两个学期 | 独立录入与删除 | 个人数据 |
| GPA | 旧学期成绩、目录学分变化 | 新记录按快照计算 | 工具 |
| 校历 | 非 14 周、缺事件 | 正确周次，不空值崩溃 | 工具 |
| 空教室 | 未录入排课 | 明确无法确认 | 工具 |
| 身份 | 两个账号 | 学期选择不破坏隔离 | HTTP |
