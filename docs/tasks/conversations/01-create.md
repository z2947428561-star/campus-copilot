## 2. 开发所需

**先读**
- `src/server.py` — 请求怎样获得可信身份和检查点标识？
- `src/auth.py` — SQLite 与 PostgreSQL 怎样共用连接入口？

- `frontend/js/app.js` — 登录和退出怎样通知聊天界面？

**已定**：沿用同源部署；会话归属由服务端校验；旧会话不删除，见本目录 plan.md。
**接口与范围**：会话 HTTP 接口及浏览器入口；新增登记表，不修改成绩和画像。
**运行**：`.venv\python.exe scripts/test_conversations.py`；`.venv\python.exe -m compileall -q src scripts`。
**未知**：本地测试曾停在导入阶段；使用有时限的诊断，先解决验证环境。

## 4. 用例

| 用例 | 输入 | 预期 | 接口 |
| --- | --- | --- | --- |
| 创建 | 同用户创建两次 | 两个独立会话 | HTTP |
| 旧会话 | 首次读取列表 | 包含原有会话 | HTTP |
| 隔离 | 另一用户的会话标识 | 404 | HTTP |
| 默认 | 不指定会话的旧聊天请求 | 使用原有会话 | HTTP |
| 切换 | 选择会话后发送 | 请求携带所选标识 | 浏览器 |
