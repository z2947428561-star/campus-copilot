# 政策证据计划

日期：2026-10-17。基线：会话生命周期完成后的 f150764。

## 1. 需求

- R-1 如实标注来源：用户要求推进架构分析第二项；人工快照不能冒充官方原文。
- R-2 证据不足时停止给结论：同一请求；低相关、缺来源和不可用须有明确状态。
- R-3 检查引用与拒答：同一请求；路由和关键词命中不能代表政策回答正确。

## 2. 大致做法

### R-1 如实标注来源

- 做法：快照记录整理方式和未知日期，分块保留章节，工具返回可追溯证据 ID。
- 涉及：公开语料、归档、建库、政策工具。
- 测试入口：归档到建库再到 search_policy 的公开入口。
- 验收：16 份快照均标人工整理；日期不臆造；旧索引标未知；偏移注明章节范围。
- 难点：旧索引不会自动获得新元数据，必须保守降级并说明重建要求。

### R-2 证据不足时停止给结论

- 做法：两后端统一余弦分数，初始阈值 0.70 可配置；拒收未知来源和社区经验。
- 涉及：检索和系统提示词；保留类别与全库合并。
- 测试入口：search_policy 工具调用，替换向量库连接。
- 验收：低分、非有限分数、无来源、空文本不返回可引用证据；故障与无证据区分。
- 难点：阈值仅筛选候选，不能证明片段覆盖问题；提示词仍须检查适用范围与时效。

### R-3 检查引用与拒答

- 做法：新增专用评测入口；离线验证规则反例，可选真实模型回答公开固定证据场景。
- 涉及：评测脚本、离线检查和使用说明。
- 测试入口：评测器公开函数和命令行；引用 ID、URL、逐字引文分别判定。
- 验收：伪造 ID、错配 URL、篡改引文、无证据仍给数值被检出；支持的引用通过。
- 难点：规则只能证明引用可追溯；语义蕴含和真实召回质量另行人工核验。

## 3. 阶段与任务

阶段 2 政策回答有可核验依据，覆盖以上三项需求。

1. 贯通来源类型、未知日期和证据定位。
2. 过滤无效证据并约束回答边界。
3. 建立引用与拒答评测并交付说明。

证明：离线回归、真实 Chroma 的确定性向量测试、评测器正反例报告。
本阶段不重新抓取官网、不改学期模型、不改索引发布方式、不自动重建现用知识库。
