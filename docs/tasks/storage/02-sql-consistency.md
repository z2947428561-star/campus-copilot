## 2. 开发上下文

**执行**：`.venv\python.exe scripts/test_storage.py`；`.venv\python.exe -m compileall -q src/storage.py src/student_data.py src/conversations.py`。

**未知**：PostgreSQL 服务不可用时，仅报告 SQL 参数与事务契约验证。

## 3. 工作流

1. 阅读上下文，重述：连接独立于鉴权，并发更新保留最初成绩快照。
2. 写事务回滚与并发更新的失败测试并提交。
3. 提取连接与路径职责，连接模块切换到公开接口。
4. 使用原子更新，通过只读、并发、重复选课与快照案例。
5. 执行测试与编译，提交实现。

## 4. 验收案例

| 案例 | 输入 | 预期 | 接口 |
|---|---|---|---|
| 回滚 | 写入后抛异常 | 没有新增记录 | 连接 |
| 只读 | 只读连接删除记录 | 拒绝写入 | 连接 |
| 并发更新 | 多次成绩更新 | 单条记录、原快照保留 | 成绩 |
| 幂等选课 | 重复并发选同一课 | 一条选课记录 | 课程 |
| 目录缺失 | 错误路径读取课程 | 不创建空库 | 公共查询 |
