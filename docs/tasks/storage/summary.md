## 2. 使用上的变化

日常检索只连接已有集合，缺失时显示不可用。新建库命令写入独立集合，通过向量、验数和自查询检查后才切换。
应用下一次检索自动发现修订，已开始的查询继续使用旧集合；旧集合保留，支持回滚。
实际命令、登记库与备份关系见[存储说明](../../storage.md)。

个人数据和会话不再调用鉴权内部连接实现。成绩使用数据库原子更新，保留首次非空快照；公共课程查询采用只读连接。
本机现用索引、个人数据库未被迁移、重建或发布；没有调用云端 Embedding。用户已有未提交修改保持独立。

## 3. 尚未验证或实现

- 真实 Milvus 发布与 PostgreSQL 集成尚未验证；目前仅有安装驱动接口、客户端替身和 SQL 参数契约证据。
- 发布登记适用于同一主机共享路径，未提供跨主机协调。
- 历史、失败和中断候选集合不自动清理，会继续占用空间；恢复需配套登记库与向量存储。
- 当前构建检查不代表真实政策问答质量，检索阈值仍需真实问题评测。
