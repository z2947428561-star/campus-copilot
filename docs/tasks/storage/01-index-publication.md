# 候选索引构建与切换

## 1. 任务位置

阶段 4 让索引安全替换；本任务贯通 R-1 重建失败仍可检索与 R-2 发布可追踪、可回滚。
前置：现有知识库访问层。后续：命令行与浏览器接入。
范围：向量集合与本机发布登记；不自动清理历史集合。

## 2. 开发上下文

**先读**
- `src/kb.py` — 哪些读取会创建或删除集合？
- `src/tools/policy.py` — 检索需要哪些返回值与评分口径？
- `scripts/test_policy_evidence.py` — 哪些来源字段必须保留？

**已定**：见同目录计划；新集合验收后切换，登记库事务检查修订号，保留旧集合。

**接口与范围**：测试入口是知识库构建、检索、发布与回滚；后端适配隐藏原生驱动差异。

**执行**：`.venv\python.exe scripts/test_chroma_rebuild.py`；`.venv\python.exe -m compileall -q src/kb.py src/kb_releases.py src/kb_backends.py`。

**未知**：Milvus 本机服务不可用时验证驱动契约，并在交付说明实际验证范围。

## 3. 工作流

1. 阅读上下文，用一句话重述：候选索引通过验证后才能替换当前索引。
2. 写失败构建不影响当前检索的失败测试并提交。
3. 实现候选集合与发布登记，使该测试通过。
4. 逐项添加并通过回滚、并发发布、缺失索引和配置不匹配测试。
5. 执行测试与编译，提交实现。

## 4. 验收案例

| 案例 | 输入 | 预期 | 接口 |
|---|---|---|---|
| 失败构建 | 第二批嵌入失败 | 当前文本不变 | 构建、检索 |
| 候选发布 | 新文本仅暂存 | 发布前旧文本，发布后新文本 | 构建、发布 |
| 回滚 | 已切换两版 | 旧文本恢复，修订递增 | 回滚、检索 |
| 发布冲突 | 两个相同基线候选 | 后发布者被拒绝 | 发布 |
| 读取保护 | 缺索引或模型变化 | 不创建集合，拒绝错误模型 | 检索 |
